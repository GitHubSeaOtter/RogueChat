# RogueChat

アスキーアートで遊ぶ、自由度の高いローグライク × LLM。
スマートフォンで操作でき、メッセージは日本語。**自由入力したコマンドの判定を毎ターン LLM（Claude）が解釈**します。

- パラメータ（HP / MP / 攻撃 / 防御 / レベル / 階層 / 金貨 / 所持品）はゲーム側で管理
- 移動・通常戦闘は決定論的に処理
- 自由入力欄に打ち込んだ任意の行動（例：「祈る」「壁を調べる」「火球を唱える」「モンスターを威嚇する」）は、現在の状態を添えて Claude に送り、結果（描写＋パラメータ増減）を適用
- **GitHub Pages のみで動く静的サイト**（ビルド不要）。APIキーは端末のブラウザに保存し、Anthropic API を直接呼び出し

## 遊ぶ

公開URL（GitHub Pages 有効化後）:

**https://githubseaotter.github.io/roguechat/**

> 初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** に設定してください。
> 以降、対象ブランチへの push で `.github/workflows/pages.yml` が自動デプロイします。

### プレイヤーキャラクター

- プレイ開始時に、**作成済みのキャラクターを選択**して冒険を始めます。
- **新規作成**では、カメラロールから**外見画像**を選べます（`<input type="file" accept="image/*">`）。
  - 画像を選ぶと、**AIが画像から名前・性格・能力（HP/MP/攻/防）を生成**します（APIキーが必要。モデルは Sonnet 4.6 固定）。
  - 画像を選ばない場合は**画像無し**となり、名前・性格・能力は**ランダム生成**（API不使用）。
- **名前と性格はいつでも編集**できます（一覧の「編集」から）。性格は自由入力コマンドのGM判定にも反映されます。
- キャラクターは端末の `localStorage` に保存されます。
- **成長（レベル・能力上昇）や獲得アイテムは、次のプレイに持ち越されません。** 毎回キャラクターの素体パラメータから開始します。

### 操作方法

- **移動**: 画面下のDパッド（8方向、**長押しで道なりに連続移動**。通路の曲がり角は自動で追従し、敵の視認・アイテム・階段・分岐で停止）/ キーボードの矢印・`hjkl`・`yubn`
- **マスを調べる**: **マップをタップ**すると、そのマスの情報（地形・モンスター・アイテム・既知の罠）がログに表示されます
- **待機**: Dパッド中央「・」/ `.`
- **隣のモンスターへ移動**: 攻撃
- **降りる**: `>` の上で「降りる」ボタン / `>` キー
- **持ち物**: 「持ち物」ボタン / `i` キー（装備の付け替え・ポーション/巻物の使用）
- **休む**: 少し回復（近くに敵がいると失敗しやすい）
- **自由入力**: 下部のテキスト欄に行動を打ち込み「実行」→ GM(LLM) が判定

### 装備・アイテム（NetHack 参考）

- **武器**（`)`）/ **防具・盾**（`[`）: 装備スロットは武器・防具・盾の3つ。強化の巻物で `+1` ずつ強化。
- **ポーション**（`!`）/ **巻物**（`?`）: 使用すると効果が発生（APIキーがあればAIが結果を判定）。
- **持ち物**から装備・使用・**捨てる（床にドロップ）**が可能。

### AI生成・状態異常・地形（NetHack 参考）

- **階のAI生成**: ゲーム開始時と階を降りた時に、その階の**テーマ・地形タイプ・モンスター群・アイテム群をAIが生成**します（APIキーが必要。無い場合は内蔵カタログで生成）。
- **地形バリエーション**: 部屋＋通路 / 迷路 / 洞窟 / 大部屋 の4系統＋**罠**（矢・毒矢・テレポート・落とし穴。踏むまで隠れています）。
- **状態異常**: 毒 / 炎上 / 出血 / 麻痺 / 睡眠 / 凍結 / 石化 / 混乱 / 朦朧 / 盲目 / 恐怖。
  プレイヤー・モンスター双方に作用し、上部のステータスバーに表示されます。
- **アイテム使用のAI判定**: ポーション/巻物を使うと、AIが**地形や周囲の敵の状態を踏まえて結果を判定**します
  （敵へのダメージ・状態異常付与、テレポート、地図表示などを反映）。

> 注: 上記AI機能は使用のたびに Anthropic API を呼び出します（モデルは設定で選択可）。
> APIキーが無い場合でも、移動・戦闘・装備・簡易アイテム使用・階層移動は内蔵ロジックで遊べます。

### APIキー

- ⚙（設定）から Anthropic の APIキーを入力します。
- キーはこの端末の `localStorage` にのみ保存され、Anthropic API へ直接送信されます（サーバを介しません）。
- 共有端末では遊んだ後に「キーを消去」してください。
- モデルは Haiku 4.5（高速・低コスト・既定）/ Sonnet 4.6 / Opus 4.8 から選択できます。

APIキーが無くても、移動・戦闘・回復・階層移動は遊べます（自由入力コマンドのみ LLM が必要）。

## 構成

```
index.html        画面とレイアウト
css/style.css     スタイル（モバイル対応・ASCII表示）
js/dungeon.js     ダンジョン生成
js/game.js        ゲーム状態・戦闘・モンスター・視界・描画・道なり移動・マス検分
js/characters.js  プレイヤーキャラクターの永続管理（localStorage）
js/llm.js         Anthropic API（構造化出力。判定=選択モデル / キャラ生成=Sonnet固定）
js/main.js        UI配線・入力・設定・キャラクター画面
docs/model-routing.md  モデルルーティング計画（フェーズ別モデル割当とコスト見積り）
.github/workflows/pages.yml  GitHub Pages 自動デプロイ
```

## ローカル確認

任意の静的サーバで配信してください（`file://` だと ES モジュールが動きません）:

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```
