# RogueChat — まだない世界

**言葉で道をつくる、ASCIIローグライク。** 記号の向こうの世界を想像し、敵の一手を読み、工夫で危機を越える。OpenAIとAnthropicに対応した、ビルド不要の静的Webゲームです。

全5階を探索し、最後の「未完の守護者」を倒すか和解して、`0`に眠る星の核を持ち帰るとクリア。死亡した冒険は終了します。画面を見て考えている間は時間が進みません。

## 遊ぶ

[GitHub Pages](https://githubseaotter.github.io/RogueChat/) で公開できます。リポジトリの **Settings → Pages → Source** を **GitHub Actions** に設定すると、`main`へのpushで配信します。URLの大文字・小文字はリポジトリ名に合わせてください。

1. 名前・性格と、渡り鳥／星読み／門番のいずれかを選んで出発。
2. 地図の記号をクリック／タップし、敵の特性や地形を観察。
3. 移動・戦闘・道具・自由行動を使い、`>`から次の階へ。
4. 第五層の守護者を越え、`0`の上で「星を持ち帰る」。

同じ「世界の種」と行動順で地形・判定を再現できます。各行動後に自動セーブし、再読込で続行。**初代のキャラクター・セーブは引き継ぎません。v2のセーブは続行でき、既存の品は補正0として保持し、新たな空腹メーターを追加します。** APIキーも旧版から自動移行しません。

## 操作

| 操作 | キーボード / 画面 |
| --- | --- |
| 移動・隣の敵への攻撃 | 矢印 / WASD / HJKL / 方向ボタン |
| 斜め移動 | YUBN / 斜め方向ボタン |
| 1ターン待機 | `.` / 中央の点 |
| 階段・星・野営地・道具の操作 | E / `>` / 「先へ進む」 |
| 持ち物 | I / 「持ち物」 |
| 野営 | R / 「野営」 |
| 護りの提案 | G / 「身を守る」 |
| 自由入力へフォーカス | `/` |
| 行動を提案 / 改行 | Enter / Shift＋Enter |
| モーダルを閉じる | Escape / 閉じるボタン |

画面はブラウザのスクロールなしで遊べる構成です。明るいASCII地図と直近3件の履歴を常に表示し、フッターの **操作／言葉／持ち物／観察** タブを切り替えます。小さい画面では履歴を1〜2件に縮め、全履歴は「履歴」から確認できます。持ち物やダイアログ内の長い一覧は、その領域内でスクロールできます。

移動先の**タップは観察**です。方向ボタンは押すと即座に1歩、320ms以上の長押しで150msごとにリピート。通路の角は自動的に曲がり、敵の視認・交差点・扉・階段・危険地形・道具の手前で停止します。拾い物や状態異常が生じた時も止まります。待機ボタンは長押しで反復しません。離す、タブ切り替え、画面を離れる、ダイアログを開く操作でも反復を終了。キーボードの長押しも同じ安全な経路追従を使います。ボタンの長押しで文字選択や長押しメニューは開きません。壁への移動や、失敗した操作はターンを消費しません。

Shift＋Sで周囲を探索できます。隣の開いた扉を選んで閉じると射線を切れます。隣の敵や扉を選んで蹴ると、集中1・1ターンで押し返したり扉を破壊できます。閉じた扉は通常移動でも開けられます。投擲・識別・合成は持ち物から操作します。

## 工夫が結果になる

自由行動は **想像 → 提案を見る → 実行** の3段階。提案と観察、持ち物の確認、取り消しはターン・資源を消費しません。

API接続時は任意の文章をGMが解釈します。たとえば：

- 「壁に名前を贈り、少しだけ退いてもらう」→ 壁を床に変える。
- 「紙の射手に未完の物語を語り、続きを考えさせる」→ 拘束して予告を消す。
- 「影を編んで羅針盤をつくる」→ ASCIIの新しい道具を床に創作。拾って持ち歩ける。
- 「孤独な守護者と、地上の星を見る約束をする」→ 永続的な和解で戦闘を回避。
- 「水に立つ敵へ雷を導く」→ 水による感電ダメージ増加。

LLMは方法と成功／失敗の描写、1〜2個の効果を提案します。**ゲーム側が対象・距離・コスト・難易度・成功率を検証し、d6で解決します。** モデルがHPや経験値を自由に書き換えることはできません。規模の大きい願いは、今できる局所的な一歩に変換します。

判定は `d6 + 能力 + 所持道具(最大1) + 近くの創作物(最大1) + floor(集中投入/2) + 消費材料あり(1)` と `難易度 + 3` を比較。実行前に成功率・集中消費・使い切る材料・成功効果・現在の攻撃予告を表示します。**失敗しても集中と材料は消費し、敵のターンが進みます。** 守護者への干渉には最低難易度5・集中投入4が必要です。

効果はダメージ、拘束、和解、回復、状態解除、護り、瞬間移動、地形変更、道具の創作、地形の開示。創作した道具の名前と説明、地形変更、和解、成功した行動の記憶はセーブされ、次の提案にも渡されます。

APIキーなしでも基本のゲーム全体と、表示された内蔵アクションを遊べます。内蔵アクションは明示した定型ルールで処理し、自由な文章をAIで解釈したようには扱いません。**内蔵アクションのボタンはAPI接続中も無料。** APIを使うのは自由入力から提案を作る時だけです。

## 考えるほど生き残れる

- 敵は次に攻撃するマスを赤く予告。予告後の1ターンで位置を変えれば回避できます。攻撃後には1ターンの隙があり、初めて見えた敵が即座に攻撃することはありません。
- 射手の狙いを壁・扉で切る、糸で足止めする、水で火を消す、油へ引火させる。地形は敵にも作用します。
- 火は紙の敵と糸紡ぎに強く、水上では弱まります。氷は予告を解除。雷は水上の敵に強くなります。
- 戦闘と和解の経験値は同じ。成長時には回復と攻撃・能力の上昇があります。
- HPは自然回復しません。安全な場所での野営は糧食を1つ消費し、HP12・集中7と状態異常を回復。野営地`&`は各階1回無料。
- 集中は6ターンごとに1回復。下降時にはHP4・集中3を回復します。通常攻撃・治癒の自由行動の最低難易度は3、治癒には最低集中3が必要です。
- 満腹度は100から始まり、3ターンごとに1減ります。0になると3ターンごとにHP2を失い、護りでも防げません。糧食を食べるか野営で回復します。最初の野営資源は2回。野営は満腹度も30回復します。単に待って集中を貯める行動にも代償があります。
- 薬、煙による拘束、入口へ戻る巻物、装備、持ち歩く道具。持ち物は18個まで。使用・装備・外す・床に置く・道具を拾う・識別・探索・投擲・合成は1ターン。
- 壁際の隠し戸を探索すると、名前のある備蓄を発見できます。蹴り壊した扉は再び閉じられません。

## 種類と個別の名前、識別、合成

持ち物と武器は **種類 → 個別名** の階層で管理します。「赤い回復薬 ×2」などの種類を開き、使う名前を選択。名前を選ばなければ、おまかせで最初の該当品を選びます。おまかせで勝手に最良の補正を選ぶことはありません。同種2個を合成する時も、別々の実体を選びます。

配置時と合成成功時に、ローカルで個別の名前を生成します。同じ名前の創作道具が生まれた場合も区別できる名前を付けます。拾い直し、投げた武器の回収、セーブ・続行で名前と補正を維持します。

通常使用の基本効果は種類ごとに固定です。回復薬はHP回復、記憶薬は集中回復、武器は攻撃補正、防具は防御補正など。個別の量・持続・装備の補正は作成時に決まり、**識別成功まで事前の数値を伏せます**。未知の補正は画面とAPIへ送る状態の両方から除きます。識別は `d6＋技・知 ≥5` で判定し、集中1・1ターンを消費。失敗しても値は変わらず、品は失いません。

「名前を活かす」から自由入力へ移ると、選んだ個別名・種類・判明している性質がGMへ渡されます。「雨音の慈雨を霧の盾にする」など、名前を活かす別の使い方を提案できます。消耗品は、GMが消費を省略してもゲーム側が選んだ実体を消費するため、失敗時にも品を使います。所持道具・武器・防具はモデルが消費を指定しない限り残ります。APIなしでは通常使用と内蔵の自由行動が使えます。

合成では材料の種類と、任意で個別名を2つ選択。集中3・1ターンを消費し、`d6＋技・知＋所持道具(最大1) ≥5` で判定します。失敗時は材料2個を失います。合成後の補正は材料からあらかじめ計算され、識別まで伏せます。

| 材料例 | 成功時に生まれる品 |
| --- | --- |
| 回復薬＋記憶薬 | 命と記憶の霊薬（HPと集中を回復） |
| 油＋煙の巻物 | 閃光の巻物（ダメージと足止め） |
| 同種の剣／鎧2個 | 補正を引き継いで強化した剣／鎧 |
| 異なる品の組み合わせ | 材料の性質に応じた薬・装備・道具など |

ロープは集中1で隣の敵を拘束し、チョークや創作した道具は集中2で護りを張れます。道具は通常使用ではなくならず、所持判定も助けます。投げた武器・防具・道具は床から回収可能。回復薬を敵へ投げると**敵が回復する**ため、投擲では種類も確認してください。

## API設定

画面右上の「内蔵ルール」または提供元名から設定を開きます。

| 提供元 | API | 既定モデル |
| --- | --- | --- |
| OpenAI | Responses API `/v1/responses`、Strict JSON Schema、`store: false` | `gpt-6-luna` |
| Anthropic | Messages API `/v1/messages`、JSON Schema | `claude-haiku-5-5` |

既存設定が旧既定モデルのままの場合は新しい既定値へ更新し、カスタムのモデルIDは保持します。モデルIDは直接変更できます。各アカウントで利用でき、対応APIと構造化出力に対応するモデルを指定してください。設定済みという表示は実際の認証成功を意味しません。

キーは選んだ提供元の固定HTTPSエンドポイントへ、ブラウザから直接送信。ゲーム状態・近くの地形・敵・名前／性格・行動履歴も判定のため送られます。サーバーやリポジトリにキーを保存しません。API利用料は各提供元から発生します。

既定は`sessionStorage`で、タブを閉じるまで保持。「この端末にAPIキーを保存する」を選んだ場合のみ`localStorage`に保存します。保存は暗号化されないため、自分の端末だけで使ってください。キーとモデルは提供元ごとに分離。「全キーを消去」は両提供元と旧版の保存キーを消去します。

提案の取得は45秒でタイムアウト。中止・認証失敗・利用上限・不完全な応答・不正な提案では、ターンや資源を消費せず、自動再試行もしません。ブラウザからのAPIアクセスは提供元のCORSポリシーに依存します。接続できない場合も内蔵ルールで遊べます。公開サービスの共有キー運用を行う場合には、別途サーバー側の認証・中継が必要です。

## 開発・検証

Node.js 22以降とPython 3を使用します。ゲーム本体に外部依存・ビルドはありません。

```sh
npm start           # http://localhost:8000
npm run check       # 構文チェック
npm test            # Node標準テスト。外部APIはモック
```

ブラウザ検証はPython PlaywrightとChromiumがある環境で実行できます。

```sh
python3 -m pip install playwright
# 先に別ターミナルで npm start
BROWSER_BIN=/usr/bin/chromium python3 tests/browser_smoke.py
```

`TEST_URL`でサーバーURL、`TEST_OUTPUT`でスクリーンショットの出力先を指定できます。テストのAPI送受信は全てモックで、実キーや課金は不要。デスクトップ、320pxの縦画面、横画面、低い表示領域でタブを切り替え、ブラウザの縦横スクロールが生じないことを検証します。実ポインターの長押し、角の追従、停止、個別名の選択、合成・識別・使用、提供元別モデルとキー、未識別情報の秘匿、APIエラー、保存・再出発・クリアも検証します。
