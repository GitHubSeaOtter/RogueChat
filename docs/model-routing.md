# RogueChat 再設計 モデルルーティング計画

model-routing スキルに基づく、開発フェーズと実行時APIのモデル割当計画。

## 品質基準(受け入れ条件)

- [ ] iPhone Safari で全機能が操作できる(ファイル選択は `<input type="file" accept="image/*">` でカメラロールが開く)
- [ ] 起動時にキャラクター選択画面が表示され、作成済みキャラクターを選んで開始できる
- [ ] 新規作成で外見画像を選ぶと、AI が名前・性格・パラメータを生成する(APIキー必須)
- [ ] 画像を選ばない場合、名前・性格・パラメータがローカル乱数で生成される(APIコストゼロ)
- [ ] 名前と性格は作成後いつでも編集できる(編集は localStorage に永続化)
- [ ] 成長(レベル・ステータス上昇)と獲得アイテムは次のプレイに持ち越されない(キャラクターの素体パラメータのみ保持)
- [ ] Dパッド長押しリピート中、通路の曲がり角では道なりに進行方向が変わり、敵の視認・アイテム・階段・分岐で停止する
- [ ] マップのマスをタップすると、そのマスの情報(地形・モンスター・アイテム・既知の罠)がログに表示される(API不使用)
- [ ] アイテム使用・自由入力は従来どおり毎回 AI が判定し、性格が判定プロンプトに反映される
- [ ] APIキーは localStorage のみに保存(既存仕様を維持)
- [ ] `node --check` が全 JS ファイルでパス、ローカルサーバ + ブラウザでスモークテストが通る

**プロンプトキャッシュは不採用**: Haiku 4.5 の最小キャッシュ対象プレフィックスは 4,096 トークンで、本アプリの system プロンプト(数百トークン)はしきい値未満のため効果がない(マーカーを付けても書き込み課金だけ発生しない静かな不発になる)。

**上位フォールバック段構え**: ユーザーは設定からモデルを Sonnet 4.6 / Opus 4.8 に切り替え可能(実装済み)。Haiku の判定品質に不満がある場合の手動フォールバックとして位置づける。

## ハンドオフ文書(実装指示書)

### 目的

RogueChat に「永続キャラクター(画像からのAI生成込み)」「道なり移動」「マップタップ検分」を追加し、成長非持ち越しを仕様として固定する。既存の ES モジュール構成・コードスタイル(2スペース、日本語UI文字列)を踏襲する。

### 成果物

| ファイル | 変更内容 |
|---------|---------|
| `js/characters.js` | 新規。キャラクター CRUD(localStorage `roguechat_characters`)、画像リサイズ、乱数生成、AI生成結果のサニタイズ |
| `js/llm.js` | `generateCharacter(portraitDataUrl)` 追加(vision、モデル固定 `claude-sonnet-4-6`)。`adjudicate` に名前・性格を反映 |
| `js/game.js` | `newGame(character)`(素体パラメータから初期化)、`runNextDir(dx,dy)`(道なり)、`describeAt(mx,my)`(検分) |
| `js/main.js` | キャラ選択/作成/編集 UI 配線、リピート移動の道なり化、canvas タップ検分 |
| `index.html` | キャラ選択パネル・作成/編集パネルの追加、HUD にキャラ名 |
| `css/style.css` | キャラ UI のスタイル |
| `README.md` | 仕様更新 |
| 変更禁止 | `js/dungeon.js`、`js/items.js`、`.github/workflows/pages.yml` |

### インターフェース契約

```js
// js/characters.js
// Character = { id: string, name: string, personality: string,
//               portrait: string|null (JPEG dataURL, 長辺192px),
//               hp: int, mp: int, atk: int, def: int, createdAt: number }
export function listCharacters(): Character[]
export function getCharacter(id): Character|null
export function saveCharacter(c): void            // 追加 or id一致で置換
export function deleteCharacter(id): void
export function randomCharacter(): Character      // 画像なし用のローカル乱数生成
export function sanitizeGenerated(raw, portrait): Character // AI出力をクランプして Character 化
export async function fileToPortrait(file): Promise<string> // dataURL

// js/llm.js
export async function generateCharacter(portraitDataUrl): Promise<{name, personality, hp, mp, atk, def}>
// 出力スキーマ: { name: string, personality: string, hp: int, mp: int, atk: int, def: int }

// js/game.js
async newGame(character)          // character.hp/mp/atk/def で player を初期化
runNextDir(dx, dy): {dx,dy}|null  // 続行方向 or 停止
describeAt(mx, my): string        // マップ座標の説明文(日本語)
```

### 値域(サニタイズ契約)

| 項目 | 値域 |
|------|------|
| name | 1〜12文字(超過は切り詰め、空なら乱数名) |
| personality | 1〜60文字 |
| hp | 16〜28(既定 20) |
| mp | 3〜10(既定 5) |
| atk | 3〜7(既定 5) |
| def | 0〜3(既定 1) |

### 道なり移動の仕様

リピートtick毎に `runNextDir(現在方向)` を呼ぶ:

1. **停止条件**(null を返す): 視界内 距離6以内にモンスター / 足元が階段・扉・アイテム・既知の罠 / プレイヤーが行動不能・混乱
2. 前方(現在方向)が歩行可能(モンスター不在)→ 同方向を返す
3. 前方不可で現在方向が上下左右の場合のみ、左右直角2方向のうち**ちょうど1つ**が開いていればその方向を返す(0 or 2つなら停止)
4. 斜め移動中の曲がりは追従しない(前方不可で停止)

初回押下は従来どおり即時1歩(攻撃も可)。リピート中はモンスターに隣接しても攻撃せず停止する。

### タップ検分の仕様

- `#screen` の click で、`render()` と同じオフセット計算(`ox = player.x - floor(viewCols/2)`)で座標変換
- 未探索(`!seen`)→「まだ見えていない場所だ。」
- 視界外の既知タイル → 地形のみ(「(記憶)壁 / 通路 / 下り階段 …」)
- 視界内 → 優先順: プレイヤー > モンスター(名前・HP・状態異常・能力) > アイテム/金貨 > 既知の罠 > 地形
- 結果は `game.message(text, 'sys')` でログに出す。モーダル・ローディング中は無視

### キャラクター UI フロー

1. 起動時: `#charselect` パネルを表示(ゲームは開始しない)。閉じるボタンはゲーム開始後のみ有効
2. 一覧の各行: ポートレート(なければ「@」プレースホルダ)、名前、性格先頭、[冒険に出る][編集][削除]
3. [新規作成] → `#charedit` を作成モードで表示
   - [外見画像を選択] → file input(`accept="image/*"`)→ リサイズ → APIキーあり: `generateCharacter` で name/personality/stats を自動入力(ローディング表示)。APIキーなし: 画像は保持しつつ乱数生成し、その旨をログに出す
   - 画像なしのまま → 乱数生成ボタンで name/personality/stats を埋める(初期表示時に自動で乱数生成済み)
   - name/personality は常に編集可能。stats は表示のみ
   - [保存] → `saveCharacter` → 一覧へ戻る
4. [編集] → 同パネルを編集モードで表示。name/personality のみ変更可(画像・stats は固定)
5. [冒険に出る] → パネルを閉じ `game.newGame(character)`。**プレイ結果はキャラクターに書き戻さない**(非持ち越し)
6. 設定パネルに [キャラクター選択] ボタンを追加。死亡時メッセージでも案内

### 実行時プロンプト仕様: キャラクター生成

- モデル: `claude-sonnet-4-6`(固定。設定のモデル選択の影響を受けない)
- 頻度: キャラ新規作成時のみ(画像選択時のみ)
- max_tokens: 400(スキーマが小さいため)
- 入力: image ブロック(base64, JPEG)+ 指示テキスト
- system(確定版): 画像の人物・生物の見た目からローグライクの冒険者プロフィールを生成。名前は日本語かカタカナで12文字以内、性格は60文字以内の一文、hp/mp/atk/def は上記値域を明示
- 出力: `output_config.format = json_schema`(既存 `callApi` を model 上書き可能に拡張して使用)
- 検証: `sanitizeGenerated()` が全フィールドをクランプ。API失敗(キー無効・ネットワーク・パース失敗)時は `randomCharacter()` にフォールバックし、その旨を表示

### エッジケースと対応

| 入力/状況 | 期待動作 |
|-----------|---------|
| 画像選択でAPIキー未設定 | 乱数生成にフォールバック+「APIキーがあれば画像から生成できます」を表示 |
| AI生成失敗(401/ネットワーク/パース) | 乱数生成にフォールバック+失敗を表示。画像は保持 |
| 巨大画像(数十MB) | canvas リサイズで長辺192px JPEG(品質0.8)に縮小してから保存・送信 |
| 非画像ファイル | `Image.onerror` で拒否しメッセージ表示 |
| localStorage 容量超過 | `saveCharacter` を try/catch し、失敗時メッセージ(古いキャラの削除を案内) |
| キャラ0件で選択画面 | 一覧に「まだキャラクターがいません」を表示 |
| プレイ中のキャラを削除 | 進行中のゲームには影響しない(次回選択時に消えているだけ) |
| 名前を空にして保存 | 乱数名で補完 |
| リピート中に混乱・麻痺 | 停止条件1で停止 |
| タップ座標がマップ外 | 何もしない |

### 禁止事項

- ダンジョン生成・アイテム定義・戦闘ロジックの変更(今回のスコープ外)
- 依存ライブラリの追加(ビルドなし静的サイトを維持)
- APIキーの localStorage 以外への保存・送信
- プレイ結果(レベル・所持品・金貨)のキャラクターへの書き戻し
